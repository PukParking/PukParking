# PukParking
PukParking is a mobile-first Progressive Web Application (PWA) designed to provide real-time, destination-based parking recommendations and pedestrian navigation for North-West University (NWU, Potchefstroom Campus) students, staff, and visitors. Instead of directing users to a specific building, it recommends the nearest valid parking area based on destination, user permissions, and crowd-assisted availability.

# Features
- Hacersine distance calculation for navigation.
- 3 different user categories: Student, Staff and Guest
